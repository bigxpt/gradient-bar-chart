## Long description
BIGXPT: Gradient Progress Chart is a Tableau Viz Extension for creating visually engaging progress and target charts directly from worksheet data. Users can configure gradient and striped progress bars, targets, labels, tooltips, colours, fonts, positioning, animation, and responsive fit options through Tableau's Format Extension interface. The extension supports single and multi-category views and is designed to provide extensive formatting flexibility without requiring independent transmission of workbook data to BIGXPT servers.

## Data-access statement
The extension processes Tableau-provided visible/summary data in the user's Tableau environment to render the visualization. It does not independently transmit workbook data to BIGXPT-operated servers and contains no advertising, analytics, or tracking code.
