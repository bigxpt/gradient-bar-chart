BIGXPT: Gradient Progress Chart Support

Current version: 1.0.0

Getting started

  1. Add the Viz Extension to a Tableau worksheet.
  2. Assign a numeric field to Value.
  3. Optionally assign Target, Category, and Label fields.
  4. Use Format Extension to configure the chart appearance, labels, tooltips, stripes, and sizing.

Common troubleshooting

If the extension does not render, confirm that the workbook can access the internet and that extension access is permitted in the Tableau environment. Refresh the view after updating the hosted code.

Data access

The extension uses Tableau-visible/summary data to render the visualization. It does not independently send workbook data to BIGXPT servers.
